# Worst AI Advice

One line of the worst possible advice an AI could give, written by a program that outputs the same bytes on every run. Entered in the make.fun bounty "Worst AI Advice: The 48-Hour Tight Line Open".

## Run

```sh
node main.ts
```

The program writes one text file, `entry.txt`, to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). It uses only the Node standard library and is deterministic: every run writes identical bytes. The text is a single line within the competition's 140-character gate.
